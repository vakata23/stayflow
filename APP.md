# StayFlow като приложение

Има два начина StayFlow да стане „приложение". Направих подготовката и за
двата — по-долу са конкретните стъпки.

| | Път A: PWA | Път B: Нативно |
|---|---|---|
| Инсталира се от | Браузъра („Добави към началния екран") | App Store / Google Play |
| Цена | Безплатно | Apple $99/год, Google $25 еднократно |
| Одобрение | Няма | Дни/седмици ревю |
| iPhone билд | Работи веднага | Изисква Mac |
| Готово ли е | ✅ Да | ⚙️ Проектите са подготвени |

> **Съвет:** започни с **Път A (PWA)**. Дава ти инсталируемо приложение на iPhone
> и Android още днес, безплатно, без магазини. Мини към нативно само ако клиент
> изрично иска приложение в магазина.

---

## Път A — PWA (готово)

Приложението вече е Progressive Web App: има manifest, икони и service worker.
Единственото условие е да е публикувано на **HTTPS адрес** (Netlify го дава
безплатно).

### 1. Публикувай онлайн (Netlify)

Виж пълните стъпки в [README.md](README.md), раздел „3. Deploy към Netlify".
Накратко:

1. Качи кода в GitHub.
2. Netlify → **Add new site → Import an existing project** → избери репото.
3. Добави environment променливите `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. **Deploy**.

### 2. Как клиентът си го „инсталира"

Пращаш линка (напр. `https://stayflow.netlify.app`) и клиентът:

- **iPhone (Safari):** бутон „Сподели" → **Добави към началния екран**
- **Android (Chrome):** менюто ⋮ → **Инсталирай приложението** (или изскача
  автоматична подкана)

След това StayFlow има икона на телефона и се отваря на цял екран, без адресна
лента — като истинско приложение.

## Път B — Нативни приложения (подготвено)

Добавих **Capacitor**, който опакова уеб приложението в нативни проекти за
Android и iOS. Папките `android/` и `ios/` вече съществуват, с брандирани икони
и splash екрани.

### ⚠️ Важно преди билд: публичен адрес

Нативното приложение зарежда кода локално на телефона, затова гост линковете и
iCal адресите трябва да сочат към реалния ти уеб домейн, а не към телефона.
Преди да билднеш за нативно, задай в `.env`:

```
VITE_PUBLIC_URL=https://вашия-сайт.netlify.app
```

(За уеб/Netlify билда остави тази променлива празна.)

### Android (работи на Windows)

**Нужно:** [Android Studio](https://developer.android.com/studio) (безплатно).

```bash
# Билдва уеб кода, синхронизира и отваря Android Studio
npm run cap:android
```

В Android Studio:
1. Изчакай Gradle да се зареди.
2. За тест: **Run ▶** на емулатор или закачен телефон.
3. За магазина: **Build → Generate Signed Bundle / APK → Android App Bundle (.aab)**.
4. Качи `.aab` в [Google Play Console](https://play.google.com/console)
   ($25 еднократна такса за акаунт).

### iOS (изисква Mac)

iPhone приложения се билдват само на macOS с Xcode — това е ограничение на Apple,
не на проекта. Опции:

- **Имаш Mac:** `npm run cap:ios`, после в Xcode: подпиши с Apple Developer
  акаунт ($99/год) и **Archive → Distribute** към App Store.
- **Нямаш Mac:** cloud услуга като [Codemagic](https://codemagic.io) или
  [Ionic Appflow](https://ionic.io/appflow) билдва iOS в облака от същия проект.

Проектът в `ios/` е готов — трябва само машина с Xcode, за да се компилира.

### След промяна в кода

Всеки път, когато промениш нещо в приложението:

```bash
npm run cap:sync
```

Това ребилдва уеб кода и го копира в нативните проекти.

## Икони на приложението

Иконите (teal фон с бяла вълна) са генерирани автоматично за всички размери —
уеб, Android и iOS. Изходните изображения са в `assets/icon.png` и
`assets/splash.png`. За да ги смениш, замени тези два файла и изпълни:

```bash
npx @capacitor/assets generate --iconBackgroundColor '#1b787c' --splashBackgroundColor '#1b787c'
```

## Кое кога да избереш

- **Продаваш на 1–20 собственика директно** → PWA е напълно достатъчно. По-евтино
  и по-бързо за поддръжка.
- **Искаш присъствие в App Store за доверие/маркетинг** → добави нативните
  приложения по-късно, когато има смисъл. Основата е готова.
